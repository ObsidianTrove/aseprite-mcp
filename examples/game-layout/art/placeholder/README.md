# Placeholder sources

placeholder marker, as do the PNG and `.tres` files exported from it.

Organize by asset type (`characters/`, `enemies/`, `tiles/`, `ui/`, ...) and choose names
you will keep: the final art for `enemies/slime.aseprite` goes in
`art/final/enemies/slime.aseprite` and replaces the same exported files.

Delete this folder once every asset has final art.
